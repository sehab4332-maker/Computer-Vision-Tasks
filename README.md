K-Means Clustering on Hypothetical Points

Objective

Apply the K-Means clustering algorithm to hypothetical data points and divide them into 4 clusters.

Methodology

1. Generate 300 hypothetical data points.
2. Apply the K-Means algorithm.
3. Divide the points into 4 clusters.
4. Calculate the cluster centroids.
5. Visualize the results using a scatter plot.

Libraries Used

* Python
* Scikit-learn
* Matplotlib

Expected Output

A scatter plot showing 4 different clusters with their centroids marked in red.
